The sample is a 2012 Forester with a P0171 (system too lean) code from a failing front A/F sensor: fuel trim stuck near +35% while warming up, and the rear O2 sensor reading rich.

Log live

Plug in a Tactrix OpenPort 2.0, turn the ignition on, then

Connecting needs Chrome or Edge on a desktop computer.

The demo replays the sample through an emulated cable and ECU, so it works without a car.

Reads CSVs from the ssm-logger desktop app and from the OpenPort's SD-card logging, and runs the same fuel-trim and sensor checks. Everything runs in your browser - nothing is uploaded.
