SSM Log Viewer

Drop a recording here, or use Open recording…

The sample is a 2012 Forester with a P0171 (system too lean) code from a failing front A/F sensor: fuel trim stuck near +35% while warming up, and the rear O2 sensor reading rich.

Reads CSVs from the ssm-logger desktop app and from the Tactrix OpenPort's SD-card logging, then runs the same fuel-trim and sensor checks. Everything runs in your browser - the file is never uploaded.
